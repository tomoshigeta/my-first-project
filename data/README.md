# 自分の資産を JSON に書いて、画面に映す

このフォルダは **本物の資産データ** を置く場所です。
手順は3つだけ。プログラムの知識はいりません。

> ⚠️ **このリポジトリは public（誰でも見られる）です。**
> `data/` に置いたファイルは `template.json` と `README.md` 以外、GitHub に上がらない設定にしてあります
> （`.gitignore`）。それでも、氏名や金額を書いたファイルは自分のPCの外に出さないでください。

---

## JSON って何？

「決まった書き方で書くメモ帳ファイル」です。中身は文字なので、メモ帳でも開けます。
書き方の決まりはたった4つ。

| 決まり | 良い例 | 悪い例 |
|---|---|---|
| 文字は `"` で囲む | `"name": "山田 太郎"` | `name: 山田 太郎` |
| 数字は囲まない・カンマを入れない | `"amount": 2000000` | `"amount": "2,000,000"` |
| 項目と項目の間に `,` を打つ。**最後の項目のあとには打たない** | `{ "a": 1, "b": 2 }` | `{ "a": 1, "b": 2, }` |
| すべて **半角** で書く（全角の `１２３` `，` `“ ”` は不可） | `"rate": 1.8` | `"rate": １．８` |

メモ（コメント）は書けません。説明はこの README にまとめてあります。

## 手順

### 1. ひな形をコピーする

`template.json` をコピーして、同じフォルダに **`my-assets.json`** という名前で保存します。

- Windows: `template.json` を右クリック → コピー → 貼り付け → 名前を変える
- Mac: `template.json` を選んで ⌘C → ⌘V → 名前を変える

`template.json` そのものは書き換えないでください（見本として残しておきます）。

### 2. 数字を自分のものに書き換える

`my-assets.json` を **メモ帳（Windows）** か **テキストエディット（Mac）** で開きます。
Word は使わないでください（勝手に記号を変えてしまいます）。
慣れてきたら [VS Code](https://code.visualstudio.com/)（無料）を使うと、書き間違いを赤線で教えてくれます。

見本の「山田 太郎」や「物件A」を自分のものに書き換え、数字を入れ替えます。
何を書くかは下の「項目の一覧」を見てください。

物件やローンが見本より少ないときは、`{ ... }` のかたまりごと消します。
多いときは、かたまりを丸ごとコピーして増やします（かたまりの間の `,` を忘れずに）。

保存するとき、文字コードを聞かれたら **UTF-8** を選びます。

### 3. 画面で読み込む

1. `mock/index.html` をダブルクリックしてブラウザで開く
2. 左下の **「JSONファイルを読み込む」** を押す
3. `my-assets.json` を選ぶ

これで3ページとも自分のデータに切り替わります。
一度読み込むとブラウザが覚えているので、次にページを開いたときもそのまま表示されます。
数字を直したら、もう一度「JSONファイルを読み込む」で同じファイルを選び直してください。
見本に戻したいときは **「サンプルに戻す」** を押します。

書き方を間違えると、右下に **「どこをどう直すか」** が日本語で出ます。
そのとおりに直して、もう一度読み込んでください。

## 項目の一覧

金額の単位は **円**（外貨は `currency` で指定した通貨）。
月ごとの金額は **1か月分**。金利は `1.8` なら年 1.8%。

### 一番外側

| 項目 | 意味 | 例 |
|---|---|---|
| `formatVersion` | この書き方の版。**触らない** | `1` |
| `owner.name` | 氏名（画面の左上に出る） | `"山田 太郎"` |
| `asOf` | 基準日。この日時点の数字であることを示す | `"2026-09-01"` |
| `rates` | 為替レート。`JPY` は必ず `1`。外貨を持っていれば追加 | `{ "JPY": 1, "USD": 155.2 }` |

### `realEstate` — 不動産（物件ごとに1かたまり）

| 項目 | 意味 | 例 |
|---|---|---|
| `name` | 物件の呼び名 | `"物件A"` |
| `address` | 所在地 | `"東京都港区白金台"` |
| `areaSqm` | 広さ（㎡） | `45.5` |
| `floor` | 階数（自由に書ける） | `"3 / 10 階"` |
| `ageYears` | 築年数 | `15` |
| `totalInvestment` | 総投資額 ＝ `ownFunds` ＋ `loan.principal` | `50000000` |
| `ownFunds` | 自己資金（頭金など、自分で出したお金） | `10000000` |
| `loan.lender` | 借入先 | `"A銀行"` |
| `loan.principal` | 当初の借入額 ＝ `balance` ＋ `cumulativeRepaid` | `40000000` |
| `loan.balance` | 残債（あといくら返すか） | `35500000` |
| `loan.cumulativeRepaid` | 累計返済額（元金ベースで、ここまでに返した額） | `4500000` |
| `loan.rate` | 金利（年 %） | `1.8` |
| `loan.termYears` | 借入期間（年） | `35` |
| `loan.monthlyRepayment` | 毎月の返済額 | `128000` |
| `monthly.rentIncome` | 家賃収入（月額） | `180000` |
| `monthly.managementFee` | 管理費（月額） | `12000` |
| `monthly.repairReserve` | 修繕積立金（月額） | `8000` |
| `monthly.propertyTaxMonthly` | 固定資産税。**年額 ÷ 12** を入れる | `9000` |

保険料は入れません（初版の決めごと）。

### `securities` — 有価証券（国内・海外 × 4クラス ＝ 8行）

| 項目 | 意味 | 例 |
|---|---|---|
| `region` | `"domestic"`（国内）か `"overseas"`（海外） | `"domestic"` |
| `assetClass` | `"株"` `"債券"` `"投資信託"` `"その他"` のどれか | `"株"` |
| `currency` | 通貨。`rates` にある通貨だけ使える | `"JPY"` |
| `cost` | 取得原価（買ったときの合計額。`currency` の通貨で） | `2000000` |
| `marketValue` | 評価額（今売ったらいくらか） | `5000000` |
| `note` | 補足（省略可）。「その他」の中身など | `"金地金"` |

8行は消さず、持っていないものは `cost` と `marketValue` を `0` にします。
（行があることで「入れ忘れ」に気づけます。）
暗号資産・金・銀などは `"その他"` にまとめます。

### `deposits` — 預貯金（口座ごとに1かたまり）

| 項目 | 意味 | 例 |
|---|---|---|
| `bank` | 金融機関名 | `"A銀行"` |
| `currency` | 通貨 | `"JPY"` |
| `amount` | 残高 | `2000000` |

### `otherLoans` — 不動産以外の借入（ローンごとに1かたまり）

| 項目 | 意味 | 例 |
|---|---|---|
| `name` | ローンの呼び名 | `"自動車ローン"` |
| `type` | 種類（自由に書ける） | `"車"` |
| `lender` | 借入先 | `"D銀行"` |
| `principal` | 当初の借入額 | `3000000` |
| `balance` | 残債 | `1800000` |
| `rate` | 金利（年 %） | `2.5` |
| `monthlyRepayment` | 毎月の返済額 | `45000` |

借入がなければ `"otherLoans": []` と書きます。

## 検算のルール（画面が自動で確かめます）

| ルール | 合わないと |
|---|---|
| `totalInvestment` ＝ `ownFunds` ＋ `loan.principal` | 不動産の棒の長さが総投資額とずれる |
| `loan.principal` ＝ `loan.balance` ＋ `loan.cumulativeRepaid` | 返済進捗率が狂う |
| `otherLoans` の `balance` ≦ `principal` | 返済済みがマイナスになる |
| `currency` は `rates` にある通貨だけ | 円換算できない |

合わないときは読み込まれず、右下にどの物件のどの数字かが出ます。

## Claude に見てもらいたいとき

チャットに `my-assets.json` の中身を **貼り付けて** ください。
それが一番安全で確実です（ファイルは GitHub に上がらないので、Claude はリポジトリからは読めません）。

金額を知られたくなければ、数字を適当に変えたものを貼っても、
書き方のチェックや画面の確認はできます。
